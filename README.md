# Summit Wilderness Adventures — Website Starter

A responsive first homepage built with plain HTML, CSS and JavaScript.

## Run it
1. Extract the ZIP folder.
2. Open the `summit-wilderness-adventures` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Edit copy and styles in `index.html` and `styles.css`; interactions are in `script.js`.

## Included
- Responsive navigation with dropdown menus
- Hero section and trip finder with interactive sample ideas
- Featured itinerary cards covering New England, Alaska, the Southwest, the Pacific Northwest and Appalachians, with illustrative durations and price ranges
- Destination cards and adventure style cards
- Planning steps, values, inquiry form and FAQs
- Mobile-friendly layout and basic SEO metadata

## Important before launch
- The current trip finder uses sample concepts only; there are no real departures, dates, pricing or inventory.
- The inquiry form opens the visitor's email app using a `mailto:` link. It does not securely submit or store leads. Connect a form backend/CRM before going live.
- No booking or payment system is connected. For real online reservations, connect a secure booking provider/backend, availability data, payment processing, confirmation emails and customer data handling.
- Confirm permits, insurance, guide qualifications, local partners and operating permissions before advertising any specific guided trip.
- The photos are loaded from Unsplash URLs and need internet access. Check each image's current license/usage terms before commercial production use, or replace them with owned/licensed assets.
- The inquiry form currently opens `summitwildernessadventures@gmail.com`; replace it in `script.js` if the business email changes.
- The footer WhatsApp link uses `https://wa.me/46707243148` for the business number `+46 70 724 31 48`.
- This is an original design inspired by common adventure-tourism website patterns, not a copy of Wildland Trekking's branding, code, or written content.
